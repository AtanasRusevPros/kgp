# Tic-Tac-Toe Game Module

This folder defines the tic-tac-toe game module.

## Subdirectories
- `contracts/`: game-specific contracts and shared types
- `web/`: web client game module
- `mobile/`: mobile client placeholder
- `backend-adapter/`: minimal backend adapter package required by the current allowlist-driven loader

## Current status
Tic-tac-toe is a simple web-only second game.
Its gameplay is local to the browser for now, while the platform still exposes it through canonical game metadata, routing, and allowlist rules.
